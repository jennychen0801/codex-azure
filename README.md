# 工程計算機（網頁版）

直接以瀏覽器開啟本目錄的 `index.html` 即可使用，無須安裝套件、啟動後端或連線。介面支援桌面與手機尺寸，不使用 CDN，不傳送算式。

## 功能

- 四則運算、括號、隱含乘法（例如 `2π`、`2(3+4)`）。
- 次方 `^`、平方根 `sqrt`、階乘 `!`、絕對值 `abs`、倒數。
- `sin`、`cos`、`tan` 及反三角函數 `asin`、`acos`、`atan`，可切換 DEG（預設，度）與 RAD（弧度）。
- `log`（底數 10）、`ln`（自然對數）、`exp`（可鍵盤輸入）、常數 `π` / `pi`、`e`。
- 科學記號輸入，例如 `1.2e-6`；ENG 顯示以 3 為倍數的指數。
- `Ans` 保留上次成功計算的未捨入結果；MC / MR / M+ / M− 記憶操作。
- 最近 10 筆計算紀錄，點選可還原算式、角度模式與當時的 Ans。紀錄與記憶值不持久化，重新整理後清除。
- `Enter` / `=` 計算、`Esc` 清除、原生文字選取與退格編輯。計算完成後輸入運算子可接續 Ans，輸入數字則開始新算式。

## 運算規則與限制

- 次方由右至左結合：`2^3^2 = 512`；次方優先於前置負號：`-2^2 = -4`。
- 隱含乘法與乘除同優先級，由左至右計算；有歧義時請加括號，例如 `1/(2π)`。
- `%` 一律代表除以 100：`200*10% = 20`、`100+10% = 100.1`，不是商用計算機的加成百分比。
- 函數需要完整括號，例如 `sin(30)`；不自動補右括號。
- 僅處理實數；除以零、定義域錯誤、溢位與無效輸入會顯示錯誤。階乘接受 0 至 170 的整數。
- 使用 JavaScript 雙精度浮點數，顯示最多 12 位有效數字；不是任意精度、符號代數或單位換算工具。工程應用請自行驗證精度與單位。
- AC 清除算式與顯示，不清除 Ans 或記憶；M+ / M− 對目前算式求值（不加入紀錄），已計算或空白時使用 Ans。
- 輸入上限為 2048 字元、512 個 token 與 64 層巢狀運算。解析器不使用 `eval` 或 `Function`。

## 開發與測試

以 Node.js 18 或更新版本執行不需額外套件的核心測試：

```powershell
node --test calculator-engine.test.js calculator-ui.test.js
```

- `index.html`：繁體中文介面。
- `calculator.css`：響應式樣式。
- `calculator-engine.js`：獨立運算解析器與數字格式化，可由瀏覽器或 Node.js 載入。
- `calculator-ui.js`：按鍵、輸入、角度模式、記憶與紀錄。
- `calculator-engine.test.js`：運算優先序、函數、錯誤處理與格式測試。

此專案為純前端網頁；執行時不需要 Python、後端服務或第三方套件。

## 介面測試範圍

calculator-ui.test.js 使用最小 DOM 測試替身驗證按鍵、記憶、紀錄、模式切換與游標編輯狀態；不等同真實瀏覽器或手機視覺測試。
